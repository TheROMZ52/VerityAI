# VerityAI

یه هم‌تیمی هوش مصنوعی برای سرور ماینکرفتت؛ فقط حواست باشه کلید API رو با رمز ادمین اشتباه نگیری.
**افزونهٔ دستیار هوش مصنوعی برای سرورهای Minecraft مبتنی بر Paper، با استفاده از [OpenRouter](https://openrouter.ai).**

[![Modrinth](https://img.shields.io/badge/Modrinth-VerityAI-1bd96a?logo=modrinth&logoColor=white)](https://modrinth.com/plugin/verityai)
[![bStats Servers](https://img.shields.io/bstats/servers/33005?label=servers)](https://bstats.org/plugin/bukkit/VerityAI/33005)
[![License](https://img.shields.io/badge/license-GPL-blue)](LICENSE)

VerityAI به بازیکنان اجازه می‌دهد مستقیماً داخل Minecraft با یک دستیار هوش مصنوعی گفتگو کنند. این افزونه از چندین مدل هوش مصنوعی، حافظهٔ گفتگو، فرمان‌ها و اتصال به افزونه‌های دیگر سرور پشتیبانی می‌کند.

**توجه:** نام این افزونه **Verity** است و هیچ ارتباطی با مود **Verity** ندارد؛ این‌ها دو پروژهٔ کاملاً جداگانه‌اند.

## قابلیت‌ها

- گفتگو با هوش مصنوعی مستقیماً داخل بازی
- سیستم حافظهٔ مکالمه
- جابه‌جایی خودکار بین کلیدهای API در صورت خطا یا محدودیت نرخ
- چند شخصیت و سبک پاسخ‌گویی
- آمار استفاده
- مینی‌مپ داخل بازی و اتصال خودکار به BlueMap و Dynmap
- یادآوری‌ها و کارهای شخصی با پشتیبانی از منطقهٔ زمانی هر بازیکن
- مأموریت‌های تولیدشده توسط هوش مصنوعی
- آموزش‌ها و راهنمای داخل بازی
- سیستم بازخورد و اصلاح پاسخ‌ها
- اتصال به افزونه‌های محبوب Minecraft

## نصب

1. آخرین فایل **VerityAI.jar** را دانلود کن.
2. فایل را داخل پوشهٔ زیر قرار بده:

```text
plugins/
```

3. سرور Paper را اجرا یا راه‌اندازی مجدد کن.
4. فایل تنظیمات در این مسیر ساخته می‌شود:

```text
plugins/VerityAI/config.yml
```

5. کلید OpenRouter را در تنظیمات وارد کن.
6. سرور را دوباره اجرا کن یا فرمان زیر را بزن:

```text
/verity reload
```

## دریافت کلید OpenRouter

1. در [OpenRouter](https://openrouter.ai) حساب بساز یا وارد حساب خودت شو.
2. بخش **Keys** را باز کن.
3. روی **Create Key** بزن.
4. کلید ساخته‌شده را کپی کن.
5. آن را در فایل `config.yml` قرار بده:

```yml
ai:
  api-keys:
    - "sk-or-v1-your-key-here"
```

می‌توانی چند کلید API وارد کنی. VerityAI در صورت نامعتبر شدن کلید فعلی یا رسیدن آن به محدودیت نرخ، به‌صورت خودکار سراغ کلید بعدی می‌رود.

> بعضی مدل‌های OpenRouter رایگان‌اند؛ مدل‌های قوی‌تر ممکن است به اعتبار حساب نیاز داشته باشند.

## فرمان‌ها

| فرمان | توضیح |
|---|---|
| `/verity reload` | بارگذاری دوبارهٔ تنظیمات |
| `/verity clear [player]` | پاک کردن حافظهٔ گفتگو |
| `/verity info` | نمایش اطلاعات افزونه |
| `/verity toggle` | فعال یا غیرفعال کردن Verity |
| `/verity personality [name]` | تغییر شخصیت پاسخ‌گویی |
| `/verity owner [player]` | مشاهده یا تعیین مالک سرور؛ بازیکن هدف باید آنلاین باشد |
| `/verity op <add\|remove\|list> [player]` | مدیریت افراد مورداعتماد با دسترسی‌های سطح مالک |
| `/verity map` | نمایش مینی‌مپ داخل گفتگو |
| `/verity stats` | نمایش آمار استفاده |
| `/verity model [name]` | مشاهده یا تغییر مدل هوش مصنوعی |
| `/verity task <add\|remove\|list\|timezone> [args]` | مدیریت یادآوری‌های شخصی و منطقهٔ زمانی |
| `/verity quest [interval <minutes>]` | ساخت مأموریت یا تنظیم ساخت خودکار مأموریت |
| `/verity tutorial <topic>` | دریافت راهنمای داخل بازی |
| `/verity feedback <good\|bad> [correction]` | ثبت بازخورد دربارهٔ پاسخ هوش مصنوعی |

## پیش‌نیازها

- Paper یا فورک سازگار، نسخهٔ **1.21 به بالا**
- Java **21 یا بالاتر**
- کلید API از OpenRouter

## افزونه‌های اختیاری

در صورت نصب بودن، VerityAI می‌تواند با این افزونه‌ها یکپارچه شود:

- PlaceholderAPI
- Vault
- LuckPerms
- Essentials
- BlueMap
- Dynmap

همهٔ این وابستگی‌ها اختیاری‌اند و افزونه بدون آن‌ها نیز کار می‌کند.

## تنظیمات

فایل اصلی تنظیمات:

```text
plugins/VerityAI/config.yml
```

از طریق آن می‌توان مدل‌های هوش مصنوعی، کلیدهای API، شخصیت‌های پاسخ‌گویی، رفتار افزونه و تنظیمات سرور را تغییر داد.

## آمار و حریم خصوصی

VerityAI برای آمار ناشناس استفاده از [bStats](https://bstats.org/plugin/bukkit/VerityAI/33005) استفاده می‌کند؛ از جمله تعداد سرورها، نسخه‌ها و میزان استفاده از قابلیت‌ها. اطلاعات شخصی جمع‌آوری نمی‌شود. هر زمان بخواهی می‌توانی از طریق `plugins/bStats/config.yml` ارسال آمار را غیرفعال کنی.

## ساخت از سورس

```bash
mvn clean package
```

فایل نهایی در مسیر `target/VerityAI.jar` ساخته می‌شود.
